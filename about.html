About Roadster Loop

Roadster Loop is a free browser game about one stunt: launch a sleek electric sports car off a giant ramp at night, flip it through a ring of lights, and land it safely. It is built to be quick to pick up and hard to master, with runs short enough to try again straight away.

How it is made

The game is built with plain HTML, CSS and JavaScript, and uses the open-source three.js library for 3D graphics. It runs entirely in your browser with no download, no account and no sign-up. The physics use a fixed 120 steps per second so a jump plays out the same way regardless of your screen's frame rate.

Original design

The car, the ramp, the city skyline and the interface are all original designs. The name and artwork do not use any car maker's logos or branding. Roadster Loop is an unofficial fan game, not affiliated with Tesla.
